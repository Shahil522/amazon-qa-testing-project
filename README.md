# Amazon India - QA Testing & UAT Project

## 📌 Project Overview

This project documents the manual QA testing and User Acceptance Testing (UAT) performed on the Amazon India web application.

The testing focused on key user journeys such as product search, filtering, cart functionality, account management, address management, and usability.

## 🎯 Objective

The objective of this project was to evaluate the Amazon India web experience from a user's perspective and identify functional, validation, usability, and user experience issues.

The testing focused on:

- Functional testing
- Exploratory testing
- Identifying bugs and edge cases
- User experience and usability observations
- UAT feedback

## 🖥️ Test Environment

- **Website:** Amazon India
- **URL:** https://www.amazon.in/
- **Browsers Tested:** Google Chrome and Microsoft Edge
- **Testing Type:** Functional Testing, Exploratory Testing, and UAT
- **Test Scope:** Search → Product Selection → Cart → Checkout/Login Stage

## 🐞 Bug Reports

The testing identified issues related to:

1. Input validation
2. Search result relevance
3. Cart functionality
4. Address field validation
5. Account name validation
6. User experience and usability

Detailed bug reports and supporting evidence are available in the project documentation.

## 🧪 Test Cases

The project includes manual test cases covering:

- Product search
- Brand filtering
- Sorting products
- Adding products to the cart
- Updating product quantity
- Removing products from the cart

## 🌐 Cross-Browser Testing

The application was tested on:

- Google Chrome
- Microsoft Edge

The main user flows were checked across both browsers.

## 🤖 Automation Approach

The identified flows can be automated using:

- Selenium WebDriver
- Java
- TestNG
- Page Object Model (POM)

Potential automated scenarios include product search, filtering, sorting, adding products to the cart, and validating cart updates.
